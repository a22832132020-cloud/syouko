ORIGINAL 8-BIT RUN & GUN

PIXEL COMMANDO

重新製作為 FC 時代魂斗羅感的原創 8-bit 像素美術：不使用受版權保護的原作素材，角色、敵人、Boss、背景皆以 Canvas 像素矩陣繪製。五關空間型地圖、每關 Boss、每關不同 BGM 與 Boss 音樂。

SELECT COMMANDO

控制：A/D 或 ←/→ 移動，W/↑/K 跳躍，S/↓ 蹲下，Space/Z/J 射擊，P/Esc 暫停。輸入創作者代碼 syouko 後，遊戲中按 G 切換無敵。

H 黃色膠囊：衝鋒槍
S 銀色膠囊：散彈槍
L 藍色膠囊：雷射
F 紅色膠囊：火焰槍
D 白色膠囊：防護罩 20 秒
C 綠色膠囊：追蹤彈 30 發

PAUSED

按 P / Esc 或觸控暫停鍵繼續。
